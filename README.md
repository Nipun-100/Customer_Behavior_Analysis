* Customer Shopping Behavior Analysis

An end-to-end Data Analytics project that explores customer purchasing patterns, spending behavior, product preferences, customer segmentation, and subscription trends using Python, PostgreSQL, and Power BI.

1. Project Overview

The objective of this project is to analyze customer shopping behavior and generate meaningful business insights that can support data-driven decision-making.

The project follows a complete data analytics workflow, starting with raw dataset exploration and cleaning in Python, followed by SQL-based business analysis in PostgreSQL, and ending with an interactive Power BI dashboard, a detailed project report, and a presentation created using Gamma AI.

2. Dataset

- **Dataset:** Customer Shopping Behavior
- **Source:** Kaggle
- **File Format:** CSV
- **Total Records:** 3,900
- **Total Columns:** 18
- **Missing Values:** 37 (Review Rating column)

* Dataset Attributes

- **Customer Demographics:** Age, Gender, Location, Subscription Status
- **Purchase Details:** Item Purchased, Category, Purchase Amount
- **Product Information:** Size, Color, Season
- **Shopping Behavior:** Previous Purchases, Frequency of Purchases
- **Additional Details:** Review Rating, Shipping Type, Discount Applied, Promo Code Used, Payment Method

4. Project Workflow

* Step 1: Data Loading & Initial Exploration
- Imported the CSV dataset into Python using Pandas.
- Inspected the dataset using `head()`, `info()`, and `describe()`.
- Checked data types, dimensions, and missing values.

* Step 2: Exploratory Data Analysis (EDA)
- Explored numerical and categorical variables.
- Analyzed statistical summaries and customer characteristics.
- Identified missing values and examined data distributions.

* Step 3: Data Cleaning & Feature Engineering
- Handled 37 missing values in the Review Rating column using category-wise median imputation.
- Standardized column names into snake_case format.
- Renamed `purchase_amount_(usd)` to `purchase_amount`.
- Created an `age_group` column using quartile-based age grouping.
- Created `purchase_frequency_days` by mapping purchase frequencies to days.
- Checked the consistency between `discount_applied` and `promo_code_used`.
- Removed the redundant `promo_code_used` column.

* Step 4: PostgreSQL Database Integration
- Connected Python to PostgreSQL using SQLAlchemy and Psycopg2.
- Loaded the cleaned DataFrame into the PostgreSQL database.
- Created a customer table for further business analysis.

* Step 5: SQL Business Analysis

Executed 10 SQL queries to answer important business questions:

1. **Revenue by Gender:** Compared total revenue generated by male and female customers.
2. **High-Spending Discount Users:** Identified customers who used discounts but spent above the average purchase amount.
3. **Top 5 Products by Rating:** Identified products with the highest average review ratings.
4. **Shipping Type Comparison:** Compared average purchase amounts between Standard and Express shipping.
5. **Subscribers vs. Non-Subscribers:** Compared customer count, average spending, and total revenue.
6. **Discount-Dependent Products:** Identified the five products with the highest percentage of discounted purchases.
7. **Customer Segmentation:** Classified customers into New, Returning, and Loyal segments.
8. **Top 3 Products per Category:** Identified the most purchased products within each category.
9. **Repeat Buyers & Subscriptions:** Analyzed subscription status among customers with more than five previous purchases.
10. **Revenue by Age Group:** Calculated revenue contributions across different age groups.

**SQL Concepts Used:**
- SELECT, WHERE, ORDER BY
- GROUP BY
- Aggregate Functions
- CASE WHEN
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER)

* Step 6: Power BI Dashboard

6. Key Results & Business Insights

The analysis generated the following insights:

* Revenue Analysis
- Male customers generated approximately $157,890 in revenue.
- Female customers generated approximately $75,191 in revenue.

* Customer Subscription Analysis
- 1,053 customers were subscribers.
- 2,847 customers were non-subscribers.
- Average spending was $59.49 for subscribers and $59.87 for non-subscribers.
- Non-subscribers generated higher total revenue due to their larger customer base.

* Product & Discount Analysis
- Gloves received the highest average review rating of 3.86.
- Hats had the highest discount-dependent purchase rate at 50%.
- Sneakers, Coats, Sweaters, and Pants were also among the most discount-dependent products.

* Shipping Analysis
- Average purchase amount for Express shipping was $60.48.
- Average purchase amount for Standard shipping was $58.46.

9. How to Run

* Prerequisites
- Python 3.x
- Jupyter Notebook
- PostgreSQL Server
- pgAdmin or another PostgreSQL client
- Power BI Desktop

* Step 1: Clone the Repository

```bash
git clone <repository-url>
cd <repository-folder>
```

* Step 2: Install Required Libraries

```bash
pip install pandas numpy sqlalchemy psycopg2-binary jupyter
```

* Step 3: Run the Python Notebook

```bash
jupyter notebook
```

- Ensure the CSV dataset is in the correct directory.
- Execute the notebook cells sequentially.
